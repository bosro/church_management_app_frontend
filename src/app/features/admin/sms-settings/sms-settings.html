Hubtel Credentials

Set these in your Supabase Edge Function secrets — not stored in the database for security.

1

Log in to your Hubtel account and go to Messaging → Manage → Programmable SMS

2

Click Details on your API Key to find your Client ID and Client Secret

3

Set these Supabase secrets via CLI:

supabase secrets set HUBTEL_CLIENT_ID=your_client_id
supabase secrets set HUBTEL_CLIENT_SECRET=your_client_secret
4

Redeploy the edge function:

supabase functions deploy send-communication
Make sure your Hubtel SMS API account is funded. Top up via Messaging → Manage → Programmable SMS → Add Funds.

GiantSMS Credentials

These are already configured in your Supabase secrets if GiantSMS is currently working.

1

Required secrets: GIANTSMS_USERNAME, GIANTSMS_PASSWORD, GIANTSMS_TOKEN, GIANTSMS_SENDER_ID

2

The GIANTSMS_SENDER_ID secret is the global fallback. Per-church sender IDs override it — set them on the Churches page.

GiantSMS sender IDs must be registered and approved on your GiantSMS account before use.
